# ClaudeTransfer
Bringing designs to Ai for the guys, hopefully reducing their workload

## Workshop Jobs Kanban

A React + TypeScript recreation of the "Workshop Jobs Kanban" design handoff — a workshop
management board for a ski/snowboard service shop (City Skis, PisteLabs). Staff use it to
check equipment in, track jobs through the service workflow on a drag-and-drop Kanban board,
add and price services, capture damage photos, and check equipment out with payment.

Built with Vite, React 19, TypeScript, Tailwind CSS, Zustand, and lucide-react.

### Getting started

```bash
npm install
npm run dev
```

Then open the printed local URL in your browser.

### Scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — type-check and build for production
- `npm run preview` — preview the production build
- `npm run lint` — run oxlint
