# ClaudeTransfer

Bringing designs to AI for the guys, hopefully reducing their workload.

## Store Management

The first design transferred: the five-page store back-office for a ski shop
(Schedules, Staff, Booking, Integrations, Printing), built from the
`Store Management Dashboard Design` handoff bundle.

- **[`frontend/`](frontend/)** — React + TypeScript + Tailwind + shadcn/ui.
  Runs on demo data with `npm install && npm run dev`.
- **[`docs/django-integration.md`](docs/django-integration.md)** — endpoint
  contract, field shapes and a DRF sketch for wiring it to Django.
